# Simulador de Caixa Eletrônico em C

Aplicação desenvolvida em linguagem C para simulação de operações básicas de caixa eletrônico em terminal, com implementação de regras de negócio para consulta de saldo, saque, depósito e encerramento do sistema.

##Principais recursos

* Validação do saldo inicial informado (impede valores negativos)
* Menu interativo em terminal
* Consulta de saldo em tempo real
* Validação de saque para impedir saldo negativo
* Validação de depósito para impedir valores inválidos
* Tratamento de opções incorretas no menu

## Tecnologias e conceitos utilizados
- Linguagem C
- Estruturas condicionais
- Estruturas de repetição
- Estrutura de seleção com `switch`
- Validação de entradas
- Controle de fluxo

## Objetivo do projeto
Este projeto foi desenvolvido com foco no fortalecimento da lógica de programação e da resolução de problemas, aplicando conceitos fundamentais da linguagem C em um sistema simples, funcional e organizado.
